# Real Testing Evidence Needed

The repository contains example images but no complete retained testing log for the three priority guides. Do not add claims about generation counts, winning tools, model performance, or exact identity until the evidence below is supplied.

## Minimum evidence for any tested-prompt claim

For each retained test:

1. Exact prompt text or immutable prompt-version identifier.
2. Tool name and official product surface used.
3. Model name/version exactly as shown at generation time.
4. Generation date and timezone.
5. Aspect ratio, seed (if exposed), reference strength, style controls, negative prompt, and other relevant settings.
6. Unedited output and a note identifying any crop, retouch, upscale, or compositing.
7. Permission and rights basis for every uploaded reference photograph.
8. Failed-output examples, not only selected successes.
9. A short factual revision note showing what changed between prompt versions.
10. Permission to publish the screenshots and outputs on AQPrompts.

## Publication rule

Until these records exist, AQPrompts may describe common issues and editorial review, but should not publish:

- “tested in every tool”;
- a specific number of generations;
- a named winning model;
- a success rate;
- “exact identity” results;
- before/after testing claims;
- a generation date, model version, or seed inferred from a filename or prompt.
